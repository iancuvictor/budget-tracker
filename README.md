# Budget Tracker and Calculator

I built this app using plain JavaScript, HTML and CSS.
You can track your budget using tools such as:
- net "profit"(savings) calculator;
- loan calculator;
- savings splitter (where your remaining funds should go)
- budget "optimiser" templates (when they will be added)
- etc, etc. (again, when added)

This app serves more as a learning experience for myself.
The website will be deployed, most likely, either thru vercel or thru netlify. Both work.
