# Budget Tracker and Calculator
[Live link for the project](https://iancu-budget-tracker.vercel.app/) (Video preview available below)

I built this app using plain JavaScript, HTML and CSS.
The project demonstrates:
- DOM manipulation
- API usage (Live currency exchange rates)
- localStorage accessing (saving, loading, parsing, bla bla)
- Overall Javascript (basic level) proficiency
- Desktop/Mobile responsive design

I decided to switch to react as soon as I got all of this down, so the project will from now remain as is. 

This app serves more as a learning experience for myself.
